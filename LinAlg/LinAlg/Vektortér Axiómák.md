tfh. V nem üres halmaz -> Vektortér valós számok fölött:
Ha:

[[Vektorösszeadás]] vagy [[Skalárszoros]] nem vezet ki belőle.

Axiómák:
1. Az összeadás [[Kommutatív]]: Bármely v1, v2 vektorra v1 + v2 = v1 + v2 = v2 + v1
2. Az összeadás asszociatív: Bármely v1, v2, v3 vektorra (v1 + v2) + v3 = v1 + (v2 + v3)
3. Létezik nullelem: v1 + 0 = v1
4. Létezik ellentett: v1 + (-v1) = -v1 + v1 = 0
5. A skalárszoros [[Asszociatív]]: Bármely v1 vektorra, és lambda, mu skalárra: (L * M) * v1 = L * (M * v1)
6. A skalárszoros disztributív a vektorokra: L * (v1 + v2) = L * v1 + L * v2  
7. A skalárszoros disztributív a skalárokra: (L + M) * v1 = L * v1 + M * v1
8. Egységszeres: Bármely v1 V -re és 1 valós számra : 1 * v1 = v1
