## Protocol
Set of rules that decide the meaning and format of packets.

## Protocol stack
The definition used for all the protocols a certain system uses.

## Multi-layer communication
 For example, 2 processes want to communicate, both on layer 3
Message gets sent through to the lowest layer, they find a common protocol, that both can agree on (Layer 1), and gets sent up the other host's layer, back to layer 3.

## Header
Also gets passed along a message to identify it. Also includes control info, like addresses that tells the destination machine where to deliver it to.

## Packets
When a message is received the receiver needs to somehow separate the message from the header, and the small parts are called headers.
